# Examples Index

This folder contains concrete, cross-domain examples showing **Limited Intelligence** as a *structural guarantee* of coherence, legitimacy, and sustainability — not as a failure mode.

Each example is framed through the conceptual ratio:

\[
C = \frac{V}{E + I + S}
\]

Where:
- **E** = Energy / cost / compute burden  
- **I** = Information throughput / noise / uncertainty  
- **S** = Structure / complexity / coupling / fragility  
- **V** = Functional value / outcome value / legitimacy  

A higher **C** indicates higher coherence per unit burden.

## Files
- `biology.md` — bounded rationality in nature and evolution  
- `ai-systems.md` — constrained models, efficiency, and reliability under limits  
- `governance.md` — alignment, safety, and legitimacy as proportional constraints
